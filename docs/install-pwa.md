# Demo als App installieren

Die Demo unter <https://opc.vompa.dev> ist eine Progressive Web App (PWA). Sie lässt sich wie eine App installieren: mit eigenem Symbol, eigenem Fenster und ohne Adressleiste. Die App heißt **KI-Leitstand** (voller Name: „Schleifwerk · KI-Leitstand“).

Die Installation ist freiwillig. Die Demo läuft genauso im Browser.

## Vorbereitung

- Öffnen Sie <https://opc.vompa.dev> im Browser. Die Erklärseite muss geladen sein, bevor Sie installieren.
- Halten Sie den Zugangscode oder Ihren Einladungslink bereit (siehe [Anmelden nach der Installation](#anmelden-nach-der-installation)).

## Windows

### Microsoft Edge

1. Öffnen Sie <https://opc.vompa.dev>.
2. Wählen Sie in der Adressleiste das Symbol **App verfügbar. KI-Leitstand installieren** (rechts im Adressfeld).
   Alternativ: **Einstellungen und mehr** (`...`) › **Apps** › **Diese Website als App installieren**.
3. Bestätigen Sie mit **Installieren**.

### Google Chrome

1. Öffnen Sie <https://opc.vompa.dev>.
2. Wählen Sie in der Adressleiste das Symbol **Installieren**.
   Alternativ: **Google Chrome anpassen und steuern** (`⋮`) › **Speichern und teilen** › **Seite als App installieren**.
3. Bestätigen Sie mit **Installieren**.

Die Menübezeichnungen können je nach Browserversion abweichen.

### Starten und deinstallieren

- **Starten:** Die App erscheint im Startmenü unter **KI-Leitstand** und öffnet in einem eigenen Fenster. Sie können sie an die Taskleiste oder an Start anheften.
- **Deinstallieren:** Öffnen Sie die App, wählen Sie im Fenster das Menü (`...` bzw. `⋮`) › **KI-Leitstand deinstallieren**. Alternativ: **Einstellungen** › **Apps** › **Installierte Apps** › **KI-Leitstand** › **Deinstallieren**.

## iPhone und iPad (iOS, iPadOS)

1. Öffnen Sie <https://opc.vompa.dev> in **Safari**.
2. Tippen Sie auf **Teilen** (Quadrat mit Pfeil nach oben).
3. Wählen Sie **Zum Home-Bildschirm**.
4. Prüfen Sie den Namen **KI-Leitstand** und tippen Sie auf **Hinzufügen**.

Hinweise:

- Ab iOS 16.4 funktioniert **Zum Home-Bildschirm** auch in anderen Browsern (zum Beispiel Chrome oder Edge), im Menü **Teilen**.
- iOS zeigt keinen Installationshinweis an. Die Installation geht nur über das Menü **Teilen**.
- Die App auf dem Home-Bildschirm hat einen eigenen Speicher. Der Browser und die App teilen sich keine Anmeldung.
- **Entfernen:** Halten Sie das Symbol gedrückt und wählen Sie **App entfernen** (Lesezeichen löschen).

## Android

### Chrome

1. Öffnen Sie <https://opc.vompa.dev>.
2. Tippen Sie auf den Hinweis **KI-Leitstand installieren**, sofern Chrome ihn anzeigt.
   Andernfalls: Menü (`⋮`) › **App installieren** (bei älteren Versionen: **Zum Startbildschirm hinzufügen**) › **Installieren**.
3. Die App erscheint im Startbildschirm und in der App-Übersicht.

**Entfernen:** Halten Sie das Symbol gedrückt und wählen Sie **Deinstallieren**.

### Samsung Internet

Öffnen Sie <https://opc.vompa.dev>, tippen Sie auf das Menü (`≡`) › **Seite hinzufügen zu** › **Startbildschirm** (oder **Zur Startseite hinzufügen**, je nach Version) und bestätigen Sie.

## Anmelden nach der Installation

Die Demo ist durch einen Zugangscode geschützt. Den Code erhalten Sie auf Anfrage; wer einen persönlichen Einladungslink hat, braucht den Code nicht.

- **Zugangscode:** Öffnen Sie die installierte App und geben Sie den Code im Feld der Erklärseite ein.
- **Einladungslink** (`https://opc.vompa.dev/#code=…`): Der Link meldet an, sobald er geöffnet wird. Die installierte App startet aber immer auf der Startseite und nimmt den Link nicht entgegen. Öffnen Sie den Link deshalb im Browser, oder geben Sie in der App den Zugangscode ein.
- Nach der Anmeldung startet das Backend (es schläft, solange niemand die Demo nutzt). Das dauert typischerweise etwa 40 Sekunden. Bis dahin zeigt die App eine Vorschau.
- Die Anmeldung gilt nur für eine begrenzte Zeit und nur für den Ort, an dem Sie sie vorgenommen haben (Browser oder installierte App). Melden Sie sich bei Bedarf erneut an.

## Updates

Neue Versionen kommen automatisch. Die App prüft beim Start, ob es eine neue Version gibt, lädt sie im Hintergrund und lädt sich einmal neu, sobald sie bereitsteht. Sie müssen nichts aktualisieren.

## Offline

Die App-Oberfläche steht auch ohne Verbindung bereit. Anlagendaten und Antworten kommen immer live vom Server und werden nie zwischengespeichert; ohne Verbindung zeigt die App deshalb keine aktuellen Daten.
